# Node.js Express API with PostgreSQL, JWT, and Sequelize

A robust RESTful API built with Node.js, Express, PostgreSQL, JWT authentication, and Sequelize ORM following the MVC architecture pattern.

## Features

- 🔐 JWT Authentication
- 🗄️ PostgreSQL Database
- 🔄 Sequelize ORM
- 🚀 Express.js Framework
- 📝 API Documentation
- 🔒 Secure Password Hashing
- 🎯 Input Validation
- 🧪 Testing Setup
- 🏗️ MVC Architecture

## Prerequisites

- Node.js (v14 or higher)
- PostgreSQL
- npm or yarn
